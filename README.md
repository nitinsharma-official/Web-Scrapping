# Web Scrapping

## About the Project
This project contains practical examples of web scraping using Python.

## Files
- `Web Scrapping.ipynb` – Jupyter Notebook containing web scraping code and practical examples.
- `phone.csv` – Dataset used for practice and data analysis.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas

## Objective
To practice web scraping, data collection, and working with CSV datasets.
